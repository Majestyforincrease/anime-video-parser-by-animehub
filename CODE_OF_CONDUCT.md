# Code of Conduct

We want this project to be useful, technical and welcoming. Participants are
expected to communicate respectfully, focus on evidence and provide actionable
feedback.

Unacceptable behavior includes harassment, discrimination, personal attacks,
deliberate disruption, publishing private information and submitting
malicious or unauthorized media credentials.

Maintainers may remove comments, reject contributions or restrict participation
when needed to keep the project safe and productive. Report conduct concerns
privately to the repository maintainers rather than opening a public issue.

# Claude for OSS Application Draft

I am applying through Anthropic's Claude for OSS program for Claude Max 20x
for six months, including Claude Code.

Claude Max and Claude Code would be used to maintain and improve Anime Video
Link Parser Kit, an open-source Python library for normalizing anime video
links from Kodik, AniLibria and AniLib/Animelib providers.

Planned uses include:

- adding regression fixtures for changing provider response formats;
- improving translation, episode and quality selection;
- reviewing URL validation and redirect security;
- expanding automated test coverage;
- maintaining documentation, examples and release notes;
- reviewing Pull Requests and helping contributors understand
  provider-specific behavior;
- investigating user-reported parser failures with reproducible test cases.

The project will not use private tokens, browser cookies, unauthorized media
links or artificial downloads, contributors or dependency claims. Any project
metrics used in the application will be verifiable and organic.
